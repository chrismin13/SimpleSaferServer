Use an existing folder

Point SimpleSaferServer at storage that is already set up and mounted outside the app.

Folder storage

Use this for ZFS, RAID, mergerfs, SnapRAID, NFS, or a normal folder. SimpleSaferServer will not mount or format anything.
The folder must already exist and be writable.
SimpleSaferServer will create .simple-safer-server/storage.json inside this folder for backup safety checks.

What changes

Storage path saved
The app stores this folder as the backup location.
Backup share points to this folder
The default backup network share is updated.
Storage marker is created
Cloud backup safety checks use the marker before sync.
No mount or format actions
The operating system or administrator keeps this folder available.
Current storage changes only after Use This Folder succeeds.
